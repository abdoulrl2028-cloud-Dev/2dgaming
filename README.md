## Controles

- WASD anda
- Shift corre
- Ctrl ou C agacha
- Botão direito do mouse mira
- Botão esquerdo atira
- R recarrega
- F é o ataque corpo a corpo
- Espaço pula
- ESC ou Espaço pula a abertura e a apresentação

A abertura da cidade vem primeiro. Depois aparece o operador, o menu e a cidade.
